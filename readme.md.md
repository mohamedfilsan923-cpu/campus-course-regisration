# Campus Course Registration Website

## Project Description
This project is a simple course registration website built using HTML and CSS. It displays available courses, provides a registration form, and includes an image and an educational video.

## Files
- `index.html`: Contains the webpage structure, course table, registration form, image, and video.
- `style.css`: Controls the colors, layout, table appearance, form styling, multimedia elements, and responsive design.

## Features
- Structured HTML table using thead, tbody, tr, th, and td.
- Registration form with text and email inputs and course selection.
- Course dropdown with at least five course options.
- Campus image with alternative text and image dimensions.
- Embedded educational video using an iframe.
- Advanced CSS selectors, including nth-child(), :hover, :required, and :focus.
- Responsive layout for mobile devices.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Ensure an internet connection is available for the external image and video.

## Technologies Used
- HTML5
- CSS3
- Git and GitHub
